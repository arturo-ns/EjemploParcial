# RecipeApp

Aplicación Android para explorar recetas destacadas y guardar las que se quieren cocinar.

- Onboarding con imagen, texto de bienvenida y botón Continuar.
- Vista principal con las pestañas Recetas y Por cocinar. Atrás no regresa al onboarding.
- Listado consumido desde la API y detalle de cada receta.
- Marcar y desmarcar recetas por cocinar, con persistencia local en Room.
